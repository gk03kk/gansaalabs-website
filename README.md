# Gansaa Labs website

The website for [gansaalabs.com](https://gansaalabs.com): a static, mobile-friendly portfolio for the Gansaa Labs software studio. Plain HTML, CSS and JavaScript, with no framework and no build step.

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8765
```

## Hosting

Hosted on GitHub Pages from the `main` branch (root folder). The `CNAME` file holds the custom domain. Every push to `main` redeploys the site.
